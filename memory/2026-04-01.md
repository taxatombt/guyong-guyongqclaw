## 重要认知升级

今天的密集学习让我对 AI Agent 的理解升级到了新层次：

1. **Agent = 模型 + Harness** — 我们造的是智能的栖居地
2. **工具系统** — 能力抽象，名字+参数+执行+返回
3. **记忆三层** — 上下文/文件/压缩机制
4. **权限门卫** — 分层规则，确认后才执行
5. **主动 Agent** — Heartbeat + Cron + Learning Loop
6. **专科医生模式** — 专业 Agent 分工，不是大模型啥都干
7. **简洁优先** — 不添加额外前言结语，直击要点
