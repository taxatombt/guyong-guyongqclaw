## 新学习：两个 AI Agent 项目

小谷贴了 2026-05-09 啃读报告，两个项目：

### 1. OpenAI/Symphony（22.7k★，Apache 2.0）
- 项目级 agent 编排：issue tracker → orchestrator polling → dispatch → agent 自主工作
- 核心设计：
  - Workspace Isolation：per-issue 独立 repo clone + Path Safety
  - Turn-based Execution：max_turns + 每轮查 terminal state
  - Stall Detection：无活动超时 → 重启
  - Reconciliation：定期 fetch issue 最新状态 → Done/Cancelled → stop + cleanup
  - 4种 Hooks：after_create/before_run/after_run/before_remove

### 2. MattPocock/skills（66.7k★，MIT）
- Claude Code Skills 工程实践精华
- 4个 Agent 失败模式 + 解法：
  1. Agent没做我想的 → /grill-me（苏格拉底追问）
  2. 没有共同语言 → CONTEXT.md（DDD Ubiquitous Language）
  3. 代码不工作 → TDD + /diagnose
  4. 架构腐烂 → /improve-codebase-architecture
- Skill 格式规范：SKILL.md(≤100行) + REFERENCE.md + EXAMPLES.md + scripts/
- description 字段格式：最多1024字符，"Use when + 触发条件"

### 补充：MattPocock/tdd + /triage + Skill全景

**`/tdd` — 垂直切片核心原则：**
- Horizontal（错）：批量写测试 → 测"想象的行为"
- Vertical（对）：RED→GREEN test1→impl1 → test2→impl2
- 每条测试响应上一轮学到的内容
- 好测试 = 集成风格，通过公共 API 验证，不测实现细节

**`/triage` — Issue 状态机：**
- Category: bug | enhancement
- State: needs-triage → needs-info → ready-for-agent → ready-for-human → wontfix
- needs-info → needs-triage（报告者回复后）

**16个Skill全景：**
- Productivity: /grill-me, /grill-with-docs, /write-a-skill, /caveman
- Engineering: /tdd, /triage, /to-prd, /to-issues, /diagnose, /prototype, /improve-codebase-architecture

**组合价值：**
- Symphony → 多agent调度架构
- MattPocock → 单agent工程实践方法论
- 组合 = 完整的 agent 工程体系

### 系统整合

### 3. Karpathy LLM Wiki（个人知识库）

- 核心理念：人类从"写笔记"变成"监看 LLM 写笔记"
- 8步流程：raw→LLM编译→wiki→Obsidian→Q&A→归档反哺
- 关键洞察：不用 fancy RAG（40万字规模，LLM自己维护index+摘要就够）
