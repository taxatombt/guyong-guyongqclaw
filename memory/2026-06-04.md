## lianghua 项目调试（2026-06-04 00:08 会话）

### 问题：API Error -2015

**错误信息：**
```
APIError(code=-2015): Invalid API-key,IP,or permissions for action.
```

**发生场景：**
- 项目能启动，能读取行情
- 下单时报错 -2015

**原因分析：**
1. IP 白名单问题（最常见，90% 概率）
2. API Key 权限不足（没开通交易权限）
3. Testnet/Real API Key 混淆
4. API Key 未正确加载

### 解决步骤（已告知用户）

1. **检查 IP 白名单**（币安官网 → API Management）
   - 如果设置了 IP 白名单 → 把服务器 IP 加进去
   - 或清空 IP 白名单（任何 IP 都能用，但安全性低）

2. **检查 API Key 权限**
   - ✅ Enable Spot & Margin Trading
   - ✅ Enable Futures（如果做合约）

3. **检查 Testnet/Real 混淆**
   - Testnet Key 不能用在实盘 API
   - 实盘 Key 不能用在 Testnet

4. **检查 API Key 是否正确加载**
   - GUI 里点「连接」看日志
   - 或检查 `api_keys.json` 文件

### 遗留问题

- [ ] 等待用户提供完整错误信息（包括请求路径）
- [ ] 确认是 IP 白名单 / Key 无效 / 还是权限不足
- [ ] 如果 Key 没问题，继续审查 L2050-L3048

### 审查进度

- ✅ L1-L2050：已读完
- ❌ L2050-L3048：被沙箱拦截，等待用户复制文件或粘贴代码

- **API -2015 错误不要慌**：90% 是 IP 白名单问题，不是 Key 本身无效
- **先问完整错误信息**：包括请求路径（/ping 还是 /api/v3/order），能快速定位问题
