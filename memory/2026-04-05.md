### 核心设计点（融会贯通）
1. **TDD for Skills** — No skill without failing test first
   - RED：跑 baseline（无 skill 时的行为）
   - GREEN：写 skill 解决问题
   - REFACTOR：堵漏洞，再测

2. **CSO (Claude Search Optimization)**
   - description = 触发条件，不是工作流总结
   - 避免 agent 跳过 skill 主体

3. **Rationalization Defense**
   - 捕获 agent 打破规则的借口
   - 建立 rationalization 表（借口 + 事实）
   - Red Flags 列表自我检查
