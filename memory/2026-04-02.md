## 学习 Pretext 项目

学习了 chenglou/pretext：纯 JavaScript/TypeScript 多行文本测量与布局库。

核心：绕过 DOM 测量的 layout reflow，用 prepare()+layout() 两步 API 实现：
- prepare() 一次性预处理（19ms/500 texts）
- layout() 纯算术热路径（0.09ms/500 texts）

设计思想可迁移到网页设计：预计算、缓存、纯算术替代昂贵操作、分层API。
