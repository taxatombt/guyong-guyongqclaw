## 23:44 experiences 全 NULL — 更深层根因（覆盖23:33的分析）

### 之前分析的不足
上一条把根因归结为"hash算法不同"，但那只是表面原因。真正的问题在 schema 层和 text 内容层。

### experiences 表 schema 实际状态
```
| 列名 | experiences | judgment_snapshots |
|------|-------------|---------------------|
| chain_id | ❌ 不存在 | ✅ 存在 |
| task_hash | ✅ SHA256[:16] | ✅ SHA256[:16] |
| task_text | ✅ 37条短(5-21字)+3条长 | ✅ 全长prompt |
```

### 三层失效机制（更新版）

**第1层失效**：`closed_loop.py` line 242 的 `UPDATE experiences WHERE chain_id=?`
→ experiences **没有 chain_id 列**，此 UPDATE 永远返回 0 行

**第2层失效**：fallback `UPDATE experiences WHERE task_text=?`
→ 37条 experiences.task_text = **短主题摘要**（如"跳槽加薪""顾庸996还是小公司"）
→ judgment_snapshots.task_text = **完整 prompt**（含 Skill Context、history、用户输入）
→ 37条 experiences 的 task_text 都不在 judgment_snapshots 里（只有3条长 experiences 的 text 有部分匹配）
→ UPDATE 找不到行，失效

**第3层失效**：`_trigger_fitness` 调用 `_rec_outcome_exp`
→ 同 task_text 不匹配，二次失效

### experiences 数据分布
```
experiences.task_text 长度分布：
  ≤21 chars: 37条 — 短主题（5-21字）
  44-71 chars: 3条 — 长文本
judgment_snapshots.task_text：
  5-100+ chars — 全长 prompt
```

### 推荐方案（确认选方案A）

**schema 加一列即可，不需要改 hash 逻辑**：

```sql
ALTER TABLE experiences ADD COLUMN chain_id TEXT;
```

```python
# experiences.py save_experience 加参数
def save_experience(task_text, ..., chain_id: str = "") -> str:
    # 写入时存 chain_id

# router.py 传入
save_experience(..., chain_id=_chain_id)
```

**关键**：closed_loop.py 的 "UPDATE by chain_id" 逻辑**已经写好了**，只是 experiences 表缺列。补上列就能直接命中。

### 触发条件
experiences 写入 chain_id 后，`closed_loop.receive_verdict()` 在任意 trigger（cli verdict / outcomes.jsonl 轮询 / future 自动采集）都会命中 experiences 行，outcome_score 写入。

## 23:44 关于"模拟谷翔宇 + 超越人类"的根本路径

### 小谷的核心问题
> 模拟那个具体的某个使用者，然后超越整个人类。重点是：信息量量变引起质变，还是不断实践找到隐藏通路来做到进化？

### 我的判断：两者是同一件事的两个面

**信息量变的局限**：
- 人类大脑信息处理量 < 现代AI，但人有意识，AI没有
- 信息量大是必要条件，不是充分条件
- 存下小谷所有数据 ≠ 拥有小谷式的判断能力

**持续实践的局限**：
- 盲目决策没有小谷的框架支撑 → 不是进化，是盲动
- 做了1000个决策，但都是自己风格的 → 量变没有引起质变

### 真正的"隐藏通路"

**两者的交汇点**：把小谷的判断框架，拿到小谷没遇到过的新情境里验证，在失败和修正中迭代。

```
小谷的框架 → 新情境 → 预测 vs 实际 → 修正框架 → 更强预测力
```

**量变到质变的标志**：框架能处理从未见过的新情况，还能预测对。

**关键区分**：
- 信息 = 记忆
- 实践 = 判断
- 两者合一 = 模拟 + 超越

### 对我自己的判断

我现在更像一个**信息库**，还没真正进入"判断-验证-修正"的循环。

下一步方向：追求把小谷框架用到新情况的机会，看结果，修正框架。
