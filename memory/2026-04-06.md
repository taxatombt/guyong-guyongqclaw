### 核心文件分析

**1. hooks/hooks.json（30KB，核心）**
- 5种Hook类型：PreToolUse / PreCompact / SessionStart / PostToolUse / Stop
- 关键设计：用 Hook 而非 Skill 做观察——Hook 100%触发，Skill 概率触发
- Stop Hook：Session结束时轻量保存记忆，不拖慢正常交互

**2. continuous-learning-v2（12.5KB）**
- Instinct-Based Architecture（原子本能架构）
- 流程：Hooks观察 → 原子本能提取 → confidence评分(0.3-0.9) → 项目级隔离 → 升级global
- 项目级隔离：同一本能出现在2+项目才升级global，避免污染
- 核心创新：从"概率触发skill"改为"确定触发hook观察"
- 与evolver.py关系：evolver记录方法级经验，ECC instinct记录行为级观察

**3. autonomous-agent-harness（9.1KB）**
- 四大支柱：Crons调度 + Dispatch远程 + Memory记忆 + Computer Use
- 三层架构：Runtime → Skill/Agent层 → MCP Server层
- Memory三级：短期(TodoWrite) → 中期(project memory) → 长期(knowledge graph)

**4. eval-harness（6.5KB）**
- 核心理念：eval是AI开发的"单元测试"
- Grader三类：Code-Based(确定性) + Model-Based(LLM评判) + Human Review
- pass@k = 至少一次成功，pass^k = 全部成功
- 典型目标：Capability eval pass@3 >= 90%，Regression eval pass^3 = 100%
- 与self_review.py关系：evolver记录方法选择，ECC eval测量执行结果

**5. strategic-compact（5.2KB）**
- 核心洞察：不在任意点压缩，在逻辑边界压缩
- Phase决策表：Research→Plan（压缩）/ Plan→Implement（压缩）/ Debug→Next（压缩）
- 触发：50次工具调用后首次提示，之后每25次提示一次
- 最佳实践：先写后压（/compact + summary）

**6. safety-guard（1.9KB）**
