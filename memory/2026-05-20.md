### 🔴 P0 致命Bug（1个）

**Bug: `position_qty` 开仓后从不更新**

- 症状：开仓成功后，state 更新了 position/entry_price/sl/tp/trailing，**唯独没有 `state["position_qty"] = qty_btc`**
- 后果：`close_position()` 读取 `state.get("position_qty", 0.001)` → **永远是默认值**
  - 实际仓位 0.005 BTC → 只平 0.001 BTC → 仓位关不掉
  - 实际仓位 0.0003 BTC → 强平 0.001 BTC → 超卖报错
- 修复位置：L1501-1508（多头）+ L1586-1593（空头）加 `state["position_qty"] = qty_btc`

### 🟡 P1 逻辑错误（2个）

1. **TRAILING_ATR vs TRAILING_STOP_ATR 命名不一致**
   - config.py 定义 `TRAILING_STOP_ATR = 1.0`
   - trend_trader.py 使用 `TRAILING_ATR`（本地默认 L221）
   - `from config import *` 导入 `TRAILING_STOP_ATR`，但代码读 `TRAILING_ATR`
   - **config 改跟踪止盈倍数无效**，永远是本地默认值 1.0

2. **累计仓位检查永远失效**
   - L1493/L1579: `state.get("position_qty", 0)` → 永远是 0（因为 position_qty 从不更新）
