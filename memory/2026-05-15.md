## 22:43-22:54 mem0 源码级深度研究 + 落地方案

小谷："学习agent memory项目，落地到自己的项目"

### 源码分析（4个核心文件全部拿到）

**`mem0/memory/main.py`**（Memory 类核心）：
- `add()` 方法：`ADDITIVE_EXTRACTION_PROMPT` 单次 LLM 调用，只 ADD 不 UPDATE/DELETE
- `_create_agent_memory()`：agent 完成操作 → 提取为 AgentFact，一等公民权重
- `_upsert_entity()`：相似实体合并（阈值 0.95），`linked_memory_ids` 双向链接
- 检索流程：向量相似度 → score_and_rank 融合 → 返回结果

**`mem0/utils/scoring.py`**（多信号融合核心）：
```python
# 融合公式
normalized_bm25 = sigmoid(raw_bm25, midpoint, steepness)  # 查询长度自适应
has_bm25:  max_possible += 1.0    # BM25 = 语义等权
has_entity: max_possible += 0.5   # 实体加成 = 半权
combined = (semantic + normalized_bm25 + entity_boost) / max_possible
```
- 语义阈值门控：语义不过关的不允许 BM25/实体"救回来"
- BM25 sigmoid 参数按查询长度自适应（short/medium/long）
- entity_boost = 0.5 * num_entity_matches

**`mem0/utils/entity_extraction.py`**（spaCy NER）：
- 4类实体：PROPER(大写专有名词)、QUOTED(引号内)、COMPOUND(名词复合)、NOUN(非复合名词回路)
- 5种过滤策略：stopword/capitalization/not-first/trigrams/acronyms

**`mem0/utils/prompts.py`**：
- `ADDITIVE_EXTRACTION_PROMPT`：从对话提取新事实，不修改已有
