2.1 compact.py — 交接框架升级
文件: workspace_tools/compact.py
来源: Codex compact 模板 + Claude Code iterative summary
核心: 压缩不是总结，是交接。输出从'摘要'改为'HANDOVER DOCUMENT'格式
RESOLVED — 已完成的事（关注结果非过程）
PENDING — 待处理（避免重复回答）
KEY DECISIONS — 关键判断+文件路径，非泛泛描述
SYSTEM — 工具/文件/压缩轮次

核心常量：
  COMPACT_PREAMBLE = (
      "You are another language model, continuing a prior session..."
      "Below is a structured handover — NOT a verbose recap.\n\n"
  )

  DIRECT_RESUME_INSTRUCTION = (
      "- Do NOT say 'Based on the summary...'\n"
      "- Do NOT recap. Resume action immediately.\n"
      "- If uncertain, state your assumption and proceed."
  )

关键洞察：'another language model' 比 'context summary' 心理距离更对
2.2 security_rule_engine.py — Hookify 风格规则引擎
文件: workspace_tools/security_rule_engine.py（新建）
来源: Claude Code plugins/hookify/core/rule_engine.py
核心: 可组合规则引擎，6种操作符，Block/Warn 双 Action
6种条件操作符：regex_match / contains / equals / not_contains / starts_with / ends_with
LRU 缓存 regex 编译（max 128 patterns）
Block（阻止）/ Warn（警告）两种 Action
Tool matcher：`*` / `Bash` / `Edit|Write` 等
YAML frontmatter + markdown body 规则文件格式
内置6条规则：dangerous_rm / curl_pipe_sh / wget_pipe_sh / fork_bomb / eval_user_input / innerHTML
支持 ~/.claude/security_rules.*.md 自定义规则

使用方式：
  from security_rule_engine import evaluate, Rule, Condition

  result = evaluate({
      "tool_name": "Bash",
      "tool_input": {"command": "rm -rf /"},
      "hook_event_name": "PreToolUse",
  })
  # result: {"decision": "block", "systemMessage": "..."}

七、核心设计原则（本周内化）
交接 > 总结：压缩不是摘要，是前后模型之间的交接文档。关键是防重复、能续上。
Hook fail-open：Hook 错误默认 allow，危险操作在 permission layer 拦截，不在 hook 层。
量化才有反馈：insights → self_model 桥接：只有量化了自己，才能知道自己变了多少。
时间维度缺失是大多数系统的通病：各系统都是瞬间态，缺跨时间态机制，导致 judgment/curiosity/emotion 不能积累。
给建议不动手是一种判断：在没有 fitness baseline 和 self_model 前，不动手比动手更诚实。
规则 > 硬编码：Hookify 风格规则引擎：YAML frontmatter + markdown body，添加规则不需改代码。
